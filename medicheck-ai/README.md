# MediCheck AI — Night Devs (CodeFlayers Hackathon 2.0, PS-11)
Frontend-only prototype. All data is fictional/synthetic; analysis and chatbot are simulated and rule-based. Not clinically validated.

    npm install
    npm run dev

Implemented: auth/demo entry, overview with animated stats + Recharts, patient search with simulated "Analyze Records", findings filters, evidence comparison modal with Mark Reviewed, rule-based chatbot, CSV export and print report.
Not yet implemented: hospital directory, document upload UI, Three.js hero, Tailwind (plain CSS used), settings/analytics pages, localStorage persistence.
